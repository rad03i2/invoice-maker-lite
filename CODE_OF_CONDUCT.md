# Code of Conduct

## Our standard

Invoice Maker Lite welcomes focused bug reports, documentation improvements, tests, and implementation contributions.

Expected behavior includes respectful technical discussion, reproducible examples using fictional invoice data, careful handling of customer privacy, and accurate feature claims.

Unacceptable behavior includes harassment, threats, discriminatory abuse, deliberate disruption, publishing private customer data, leaking credentials, or using real invoices as public test fixtures without permission.

## Scope

This applies to issues, pull requests, reviews, discussions, and other project spaces controlled by the maintainer.

## Enforcement

Maintainers may edit, hide, lock, or remove disruptive content and may restrict participation when necessary.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md) rather than being disclosed in a public issue.
