# Invoice Maker Lite Brand Guide

Invoice Maker Lite uses a visual system named **Ledger Paper**: premium editorial invoice stationery combined with compact local software cues.

## Personality

- **Professional** — suitable for billing and client-facing documents.
- **Calm** — avoids noisy fintech gradients and dashboard clutter.
- **Local-first** — the product feels like a dependable CLI utility, not a cloud SaaS.
- **Precise** — financial totals, status, and document hierarchy are visually prominent.

## Palette

| Role | Color | Hex |
|---|---|---|
| Paper base | Warm ivory | #F4F0E7 |
| Primary | Deep emerald | #123B35 |
| Primary dark | Ledger green | #0B2B27 |
| Accent | Muted gold | #C9A05C |
| Main text | Ink green-black | #14251F |
| Muted text | Warm stone | #6E6253 |

Emerald communicates trust and record-keeping. Muted gold adds a premium document feel.

## Logo

`assets/project-logo.svg` combines a clean invoice sheet, ledger lines, and a verified status seal.

Do not add unrelated banking, cloud, or payment-provider imagery. The current project records invoices but does not process payments.

## Hero cover

`assets/project-cover.svg` shows a stylized invoice with totals and status, plus the project name and author attribution.

Use fictional invoice identifiers and values only. Never place real customer data in repository artwork.

## Typography and layout

Use a serif headline style for the product name when possible, paired with a modern system sans-serif such as Inter, Segoe UI, or Arial for technical content.

Favor generous whitespace, paper-like surfaces, clear table rules, invoice status chips, quiet borders, and editorial hierarchy.

## Voice

Prefer exact language:

- “HTML export suitable for browser printing” instead of “native PDF export”.
- “three-letter ISO-style code” instead of claiming full currency-registry validation.
- “local SQLite database” instead of “encrypted storage”.
- “status tracking” instead of “payment verification”.
- “no network requests” instead of implying automatic privacy guarantees.

Accuracy is part of the brand.
