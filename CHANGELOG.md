# Changelog

Notable repository-facing changes are recorded here.

The package currently declares version **1.0.0** in `pyproject.toml`. This changelog does not invent release tags or dates that are not present in the repository.

## Unreleased

### Added
- Independent **Ledger Paper** visual identity.
- Repository hero cover and square project logo.
- Separate English and Arabic guides.
- Architecture and brand documentation.
- Support guide, code of conduct, issue forms, pull-request template, and CODEOWNERS.

### Changed
- Rebuilt the main README as a product-style GitHub landing page.
- Expanded documentation for SQLite storage, invoice lifecycle states, HTML/JSON export, decimal calculations, and overwrite behavior.
- Clarified that PDF output relies on browser printing rather than a bundled PDF engine.
- Clarified currency validation and local-database security boundaries.
- Expanded contribution and security guidance.

### Unchanged
- Invoice calculations and persistence behavior.
- CLI commands and public behavior.
- Runtime dependency model.
- Test suite and CI matrix.
